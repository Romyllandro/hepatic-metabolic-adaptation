# legacy/

Entry points, expected counts and figures from an earlier (9 Sep 2026) version of this package, in which
pFBA was the primary solver for RQ1 and RQ2. After the 21 Sep 2026 revision decision, standard FBA became
primary and pFBA a sensitivity analysis. These files are kept only to document that history; use
`run_pipeline.py` in the repository root.
